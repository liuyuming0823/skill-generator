# 技能命名与可发现性

技能上架后能不能被人搜到，**name 只占一部分**。这份文档记录的是实测结论，不是经验之谈。

## 一、三层可发现性模型

搜索引擎同时吃四个字段，权重和覆盖范围不同：

| 层 | 字段 | 作用 | 优化手法 |
|---|---|---|---|
| 1 | `name`（slug） | 唯一标识；搜 "skill" 类宽泛词时靠前缀命中 | 选**零重名**的高频词根 |
| 2 | `display_name` | 列表页第一眼；中文搜索主力 | 堆能力关键词，用 `·` 分隔 |
| 3 | `description` / `description_zh` | 语义搜索主力，**长尾词全靠这里** | 穷举用户可能说的同义说法 |
| 4 | `category` | 分类榜单与过滤器 | 落到平台枚举内的正确分类 |

**关键实测**：搜「打包技能」时，排第一的是一个 name 里完全没有"打包"二字的技能——它靠的是中文描述里的同义词穷举。**中文查询基本只匹配中文描述，不看英文 name。**

## 二、词根占位：先查再占

上架前务必先搜一遍候选词根，看有没有被占。实测数据（SkillHub）：

| 词根 | 已占 | 判定 |
|---|---|---|
| `creator` | 8+（含平台内置同名技能） | 已饱和，避开 |
| `maker` | 7 | 已饱和，避开 |
| `forge` | 6（其中 `ocas-forge` / `axiomata-skill-forge` 功能高度重合） | 语义已泛化，避开 |
| `audit` | 5 | 单一功能赛道拥挤 |
| `generator` | 4，**但全部带前缀**（`jc-` / `book-` / `verifier-` / `greeting-`） | 纯名可占 |
| `studio` | 2（两个同名，且都是"生成+校验+发布"） | 已被占，避开 |
| `kit` | 2（`skill-kit` 也是多能力工具包） | 已被占，避开 |
| `foundry` | 1（`skill-foundry`） | 已被占 |
| **`skill-generator`（精确名）** | **0** | **可占** |

> 平台**允许重名**（`skill-studio` 有两个、`skill-creator` 有八个都在架上）。但重名对冷启动最不利：用户搜到后无法分辨该装哪个。**零重名优先级高于词根好听。**

## 三、关键词穷举法

description 的写法不是"把功能说清楚"，而是**把用户可能说的所有说法都写进去**。

反例（只描述功能）：
```
技能打包与迁移工具。
```

正例（穷举同义词，实测能把长尾查询全部吃下）：
```
技能打包与迁移工具。当用户提到打包技能、导出技能、迁移技能、备份技能、
skill备份、skill迁移、skill导出、skill打包时触发。
```

明哥的 skill-generator 同理，description 里同时覆盖：

- 生成侧：做个技能 / 生成技能 / 新建技能 / 写个 skill / create skill / build skill
- 打包侧：打包技能 / 技能打包 / 存成技能 / 导出技能 / package skill
- 上架侧：技能上架 / 技能合规检查 / 市场分发字段
- 质量侧：技能体检 / 安全体检 / 绝对路径 / 明文凭据

## 四、起名检查清单

生成或上架一个新技能前，逐条过：

1. `name` 是否 kebab-case（小写字母 + 数字 + 连字符）——平台硬要求，中文名会被拒
2. 到平台上搜一遍这个精确名，**有重名就换**
3. 词根是否落在红海区（对照上表）
4. `display_name` 是否带了至少两个能力关键词
5. `description` 是否穷举了同义说法（中文 + 英文）
6. `description_zh` 是否含中文（平台会校验语言是否匹配）
7. 四个展示字段里都不能有 `<` `>`（市场校验会直接失败）
8. `category` 是否落在平台枚举内——**枚举值需向平台确认，不要凭感觉填**
9. 中文触发词全部放进 `description`，不要指望 `name` 承载中文搜索

## 五、一个反直觉的结论

**不要为了"名字更全面"而把能力全塞进 name。** `skill-generator-packager` 这类名字：

- 太长，用户不会念、不会拼、不会搜
- 每个词根都被稀释，前缀匹配反而更难命中
- 平台展示时被截断

正确做法是 **name 保持短而干净 → display_name 承载功能词 → description 承载长尾词**。三层各司其职。
